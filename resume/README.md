# Resume Storage

Place the primary resume PDF in this folder with this exact filename:

`Satyendra_Kumar_Namdeo_Resume.pdf`

MultiApply automatically tries to load this file when the dashboard opens. If the PDF is not present, the application falls back to its built-in resume copy so the compose screen remains usable.

## Recommended file

- Filename: `Satyendra_Kumar_Namdeo_Resume.pdf`
- Format: PDF
- Purpose: default attachment for job applications

Do not store passwords, API keys, tokens, or other secrets in this folder.
